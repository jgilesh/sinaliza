# Sinaliza · Dicionário de Libras

Dicionário de Libras para consulta rápida, no celular ou no computador. Digite uma palavra em português (sem precisar de acento) e o sinal aparece na hora, com um desenho animado e os parâmetros: mão, local, movimento, palma e expressão.

- Demo com 5 sinais: água, café, família, obrigado e você.
- Desenhos próprios, feitos por `scripts/desenhar_sinais.py`. Referência de como cada sinal é feito: Dicionário da Língua Brasileira de Sinais (INES).
- Funciona sem internet depois da primeira visita.

Rodar no computador:

```bash
python3 -m http.server 4210
```

Depois abra http://127.0.0.1:4210
